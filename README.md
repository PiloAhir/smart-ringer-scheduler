# Smart Ringer Scheduler

A simple Kotlin Android app to schedule Ring, Vibrate, or Silent/DND mode by weekday.

## Build

Push to `main` or use Actions → Build Android APK → Run workflow. Download the `smart-ringer-scheduler-debug-apk` artifact from the completed run.

## Permissions

Allow exact alarms in Android settings. For Silent/DND mode, grant Notification Policy Access in the app. Android may restrict background activity; test scheduled changes on your device.
